# FoodScope AI — პირველი სამუშაო პროტოტიპი (v0.1)

ეს არის ტელეფონზე გამოსაყენებელი **PWA ვებაპლიკაცია**. მისი განთავსება შესაძლებელია GitHub Pages-ზე; ინსტალაციაც შესაძლებელია Android Chrome-იდან. ZIP ჯერ **არ არის APK/AAB** და Play Store-ზე პირდაპირ ვერ აიტვირთება.

## უკვე მუშაობს

- ქართულ, ინგლისურ და რუსულ ენებზე ინტერფეისი;
- შტრიხკოდის წაკითხვა კამერით Android Chrome-სა და სხვა მხარდაჭერილ ბრაუზერებში (BarcodeDetector API, HTTPS აუცილებელია);
- ფოტოზე შტრიხკოდის ამოცნობა, თუ ბრაუზერს აქვს BarcodeDetector;
- კოდის ხელით შეყვანა (EAN-8/EAN-13, UPC-A და GTIN-14 საკონტროლო ციფრის შემოწმებით);
- რეალური პროდუქტის მონაცემების მოძიება Open Food Facts v3 API-დან;
- Nutri-Score (თუ ხელმისაწვდომია), NOVA, კვებითი ცხრილი, ინგრედიენტები, ალერგენების ჩანაწერები, დანამატების ჩანაწერები;
- მარტივი 0–100 ვიზუალური გარდაქმნა **A=90, B=70, C=50, D=30, E=10**. ეს **არ არის სარგებლის პროცენტი** და არ ცვლის Nutri-Score-ის ოფიციალურ ალგორითმს;
- ისტორია მოწყობილობაზე და ორი სკანირებული პროდუქტის შედარება;
- საიტის ნაწილობრივი ოფლაინ გახსნა PWA-თი. ახალი პროდუქტების მოძიებას ინტერნეტი სჭირდება.

## GitHub Pages-ზე ატვირთვა

1. GitHub-ში შექმენი **ახალი საჯარო რეპოზიტორია**, მაგალითად `foodscope-ai` (არსებული Domino Georgia, CarDoc AI ან Thermohut არ შეცვალო).
2. ამ ZIP-იდან **ამოიღე ყველა ფაილი** და რეპოზიტორიის მთავარ დირექტორიაში აიტვირთოს `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, `icon*.png`, `icon.svg` (და README სურვილის მიხედვით). **ZIP-ის როგორც ერთი ფაილის ატვირთვა არ გამოიტანს საიტს.**
3. Settings → Pages → Deploy from a branch → `main` / root → Save.
4. მისამართი დაახლოებით იქნება `https://YOUR-USERNAME.github.io/foodscope-ai/`. საიტი აუცილებლად HTTPS-ით გახსენი.
5. მობილურზე აპის ხატულისთვის Chrome-ის მენიუში მოძებნე "Add to Home screen" ან "Install app".

ტესტი: ხელით შეიყვანე პროდუქტის რეალური GTIN, მაგალითად `3017620422003`. შედეგი გამოჩნდება მხოლოდ თუ ინტერნეტი მუშაობს და პროდუქტი მოცემულია Open Food Facts-ში. კამერის სკანირება ფაილიდან (`file://`) არ იმუშავებს.

## მონაცემების, უსაფრთხოებისა და ჯანმრთელობის შენიშვნები

- **შტრიხკოდი კვებით მონაცემებს არ შეიცავს**. კოდი მხოლოდ პროდუქტის ჩანაწერის საძიებლად გამოიყენება.
- API ინფორმაციის სისრულე დამოკიდებულია პროდუქტზე და ქვეყანაზე. არარსებული ალერგენული მონაცემი არ ნიშნავს ალერგენების არქონას. შეამოწმე ეტიკეტი.
- 0–100 ქულა არის Nutri-Score-ის **მარტივი ინტერფეისური გარდაქმნა**, არა მეცნიერულად გამოთვლილი სარგებლობა პროცენტულად. სხვაობა 90-სა და 70-ს შორის არ ნიშნავს ჯანმრთელობის 20%-იან სხვაობას.
- ამ ვერსიაში **ნამდვილი AI ანალიზი და პროდუქტის უკეთესი ალტერნატივების ძიება ჯერ არ არის**. მათთვის საჭიროა წყაროების შემოწმება, უსაფრთხო გამოთვლები და ცალკე backend.
- Open Food Facts API-ის შეზღუდვები ვრცელდება ინდივიდუალურ IP-ებზე (პროდუქტის მოძიებაზე დაახლოებით 15 მოთხოვნა წუთში; გადამოწმება აუცილებელია გაშვებამდე). უფრო მასშტაბური პროდუქტის დასაწყებად საჭიროა ქეში და წესების შესაბამისი backend.
- Open Food Facts-ს ესაჭიროება მოთხოვნებზე აპის სწორი User-Agent იდენტიფიკაცია. ბრაუზერში `User-Agent` ხელით ვერ იცვლება, ამიტომ ეს MVP იყენებს `X-User-Agent`-ს. ფართო გამოშვებამდე აუცილებელია საკუთარი API proxy საიდენტიფიკაციო სათაურით და საკონტაქტო მისამართით.
- მონაცემთა ბაზის ლიცენზია **ODbL**; პროდუქტის ფოტოებზე გამოიყენება **CC BY-SA**. საჭირო იქნება მონაცემთა წყაროს ატრიბუცია, გადამოწმება და ლიცენზიის სხვა პირობების დაცვა.
- ისტორიას ინახავს ბრაუზერი `localStorage`-ში. მომხმარებელს შეუძლია მისი წაშლა. საიტს არ აქვს რეგისტრაცია ან ანალიტიკის SDK.
